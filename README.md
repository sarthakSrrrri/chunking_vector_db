# Chunking & Vector DB Best Practices

Advanced document chunking techniques and vector database best practices for
building high-quality retrieval (RAG) pipelines.

## What this repo covers

- **Chunking strategies** — fixed-size, recursive, semantic, and structure-aware
  (markdown/code/table-aware) chunking, with guidance on choosing chunk size and
  overlap for different content types.
- **Embedding & indexing** — tips for generating embeddings and indexing them
  efficiently in a vector database.
- **Vector DB best practices** — metadata filtering, hybrid search (keyword +
  vector), re-ranking, and index tuning for better retrieval accuracy.
- **Evaluation** — simple ways to measure retrieval quality (precision/recall,
  manual eval sets) so changes can be compared objectively.

## Goal

Improve the relevance and accuracy of information retrieved for RAG and
search use cases by applying proven chunking and vector DB techniques.

## Status

Work in progress — techniques and examples will be added incrementally.
